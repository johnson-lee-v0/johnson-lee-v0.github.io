Blackjack Decision Simulator

A six-deck Python desktop simulator combining playable blackjack, strategy tables, betting mechanics, event logging, a remaining-card tally, and exploratory hand-state analysis.

  • Python
  • SQLite
  • Desktop UI
  • K-means

Question

How can a game become an analyzable system?

Capture decisions and outcomes inside a playable environment, then make the resulting behavior available for later analysis.

Approach

Build the loop and the data layer

Combine game-state logic, a desktop interface, strategy tables, a remaining-card tally, betting mechanics, and SQLite event storage.

Output

Gameplay plus exploratory clustering

Logged hand states and actions can be explored after play using an experimental K-means view.

Product views

Playable interface and decision table

Use the controls or arrow keys to move through the application views.
