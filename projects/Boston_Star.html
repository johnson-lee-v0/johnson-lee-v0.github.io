Celtics game analysis

From shot selection to game outcomes: exploring Celtics player data and the signals associated with a win.

Python · Exploratory analysis · Classification

Start with the shots

Before comparing models, the analysis explored how Jayson Tatum and Jaylen Brown's shot profiles changed across seasons. The charts make changes in shot location and volume easier to see than a season-average table alone.

Game data was scraped from Basketball Reference, transformed into team and player features, and filtered to end-of-third-quarter statistics. Naive Bayes, KNN, and SVM models were then compared using 2018–2022 for training and 2023 for testing.
